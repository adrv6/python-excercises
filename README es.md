# 🐍 Ejercicios de Python
Una colección de ejercicios de Python para principiantes completados a través de [Codedex](https://www.codedex.io/) y [Codewars](https://www.codewars.com/), organizados por tema. Este repo documenta mi proceso de aprendizaje mientras me familiarizo con los fundamentos de Python.
> Hecho por [@adrv6](https://github.com/adrv6)
---
## 📂 Estructura

**`Conditionals/`** — Ejercicios usando `if`, `elif` y `else` para manejar distintas condiciones y ramas lógicas.

**`Loops/`** — Ejercicios centrados en bucles `while` y control de iteraciones.

**`List and functions/`** — Ejercicios que combinan manipulación de listas con funciones y parámetros.

**`Codewars/`** — Soluciones de katas de Codewars, cada una resolviendo un problema o algoritmo específico.

---
## 🧠 Temas cubiertos
- Condicionales (`if`, `elif`, `else`)
- Bucles (`while`, `for`)
- Listas y métodos de listas
- Funciones y parámetros
- Módulo `random`
- Entrada de usuario con `input()`
- Formateo de strings con f-strings

## ▶️ Cómo ejecutar
Asegúrate de tener Python 3 instalado. Luego ejecuta cualquier archivo así:
```bash
python coin_flip.py
```
Algunos ejercicios requieren entrada del usuario — sigue las instrucciones que aparecen en la terminal.
---
## 📌 Notas
Estos son ejercicios de aprendizaje, no código de producción. Algunos archivos son intencionalmente simples — el objetivo era entender el concepto, no escribir la solución más optimizada.
